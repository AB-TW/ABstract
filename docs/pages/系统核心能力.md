## 核心业务能力
- 配置管理
    1. Feature 管理
        1. 提供Feature Config的元数据
    2. Feature Config管理
        1. 提供依据Feature 生成Feature Config 配置界面的能力
- 实验管理
    1. 实验管理
        1. 提供实验、分组、指标配置的管理功能
        2. 提供实验实验运行结果查看
    2. 实验分级管理
        1. 提供互斥组管理
        2. 互斥组中的实验流量之间互斥
    3. 实验执行阶段分组结果查询能力
- Tracking 数据收集
    埋点事件上报收集
- 配置发布
	- 提供统一的通过featureKey 获取配置的结果，统一Feature Config 和实验配置下发结果
