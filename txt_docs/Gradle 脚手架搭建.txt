-   tags： #Gradle

-   ## 构建项目脚手架

-   ### 技术栈

    编程语言： Java 17

    软件构件工具： Gradle 8.1.1

    基础框架： Spring Boot 3.X

    Web框架：Spring WebFlux、Spring RSocket

    数据库： #CouchBase + Spring Data reactive CouchBase \### 架构风格

使用 Smart Domain 三层架构模式。 - \### 创建脚手架项目步骤： -
创建项目根目录 1.
在您要创建项目的目录下,使用命令行初始化项目:`gradle init` 2. 选择Gradle
Daemon 为 1 basic

    ```
    Starting a Gradle Daemon (subsequent builds will be faster)

    $ Select type of project to generate:
      1: basic
      2: application
      3: library
      4: Gradle plugin

    $ 1
    ```

    1.  选择script DSL，这里选择1: Groovy

    ```
    Select build script DSL:
      1: Groovy
      2: Kotlin
    ```

    1. 输入项目名称。

    当前目录下将生成`build.gradle`和`gradle`文件夹等。

    1. build.gradle 中配置spring boot 和 dependency-management插件
        
        ```
        plugins {
            id "org.springframework.boot" version "3.0.6" apply false
            id "io.spring.dependency-management" version "1.1.0" apply false
        }
        
        repositories {
            mavenCentral()
        }
        ```

-   添加 buildSrc 脚本
    1.  创建 buildSrc目录

    2.  创建 build.gradle文件

        ``` groovy
        plugins {
            id 'groovy-gradle-plugin'
        }
        ```

    3.  创建buildSrc/src/main/groovy

    4.  创建domin.plugin

        ``` groovy
        plugins {
            id 'java'
            id 'jacoco'
            id 'checkstyle'
            id 'pmd'
        }

        group 'cn.dpc.ab'
        version '1.0-SNAPSHOT'

        repositories {
            mavenCentral()
        }

        java {
            sourceCompatibility = JavaVersion.VERSION_17
            targetCompatibility = JavaVersion.VERSION_17
        }

        dependencies {
            testImplementation  'org.junit.jupiter:junit-jupiter-api:5.9.2'
            testRuntimeOnly 'org.junit.jupiter:junit-jupiter-engine:5.9.2'
            implementation 'org.projectlombok:lombok:1.18.26'
            annotationProcessor 'org.projectlombok:lombok:1.18.26'
            implementation 'io.projectreactor:reactor-core:3.5.5'

            testImplementation 'org.projectlombok:lombok:1.18.26'
            testAnnotationProcessor 'org.projectlombok:lombok:1.18.26'
            testImplementation 'org.mockito:mockito-core:5.2.0'
            testImplementation 'org.mockito:mockito-junit-jupiter:5.2.0'
            testImplementation 'io.projectreactor:reactor-test:3.5.5'
        }

        test {
            useJUnitPlatform()
            finalizedBy jacocoTestReport
        }

        jacocoTestReport {
            dependsOn test
        }

        checkstyle {
            toolVersion = '10.10.0'
            sourceSets = [sourceSets.main]
            ignoreFailures = false

            configFile file("${rootDir}/config/checkstyle/checkstyle.xml")

        checkstyleMain {
            source = ["src/main/java"]
        }

            source = ["src/test/java"]

        check.dependsOn 'checkstyleMain'
        check.dependsOn 'checkstyleTest'

        pmd {
            toolVersion = '6.52.0'
            sourceSets = [sourceSets.main]
            ruleSets = ["${rootDir}/config/pmd/pmd-ruleset.xml"]
            rulesMinimumPriority = 3
            ignoreFailures = false
            consoleOutput = true
        }

        check.dependsOn 'pmdMain'
        check.dependsOn 'pmdTest'
        ```

-   创建domain层子模块
    1.  在根项目中添加如下路径和文件

            domain/
                build.gradle
                src/
                  main/
                    java/
                    resources/
                  test/
                    java/
                    resources/

    2.  根项目中setting.gradle中增加

            include 'domain'

    3.  修改build.gradle

            plugins {
                id 'domain'
            }
-   创建persistent层子模块
    1.  buildSrc/src/main/groovy 目录下创建persistent.gradle

        ``` groovy
        plugins {
            id "domain"
            id "io.spring.dependency-management"
        }

        dependencyManagement {
            imports {
                mavenBom "org.springframework.boot:spring-boot-dependencies:3.0.6"
            }
        }

        dependencies {
            implementation 'org.springframework.boot:spring-boot-starter-data-couchbase-reactive'
            annotationProcessor 'org.springframework.boot:spring-boot-configuration-processor'
            testImplementation 'org.testcontainers:couchbase:1.18.0'
            testImplementation "org.testcontainers:junit-jupiter:1.18.0"
            testAnnotationProcessor 'org.springframework.boot:spring-boot-configuration-processor'

            testImplementation 'org.springframework.boot:spring-boot-starter-test'
        }
        ```

    2.  在根项目中添加如下路径和文件

            persistent/
                build.gradle
                src/
                  main/
                    java/
                    resources/
                  test/
                    java/
                    resources/

    3.  根项目中setting.gradle中增加

        ``` groovy
        include 'persistent'
        ```

    4.  修改build.gradle

        ``` groovy
        plugins {
            id 'persistent'
        }
        ```
