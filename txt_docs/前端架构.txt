    -   测试策略：

    -   #### 1 .View

        采用 功能测试，属于第二象限的测试 由于View
        布局、样式难以用代码进行测试，因此需要手动测试这部分的功能
        测试时，依赖于bff，用stub来代替组件

    -   #### 2.View ViewModel

    -   采用 组件测试，属于第一象限的测试
        View、ViewModel是紧密绑定在一块的，这个是一起测试的原因，采用组件测试，是因为可以更快速的验证
        测试时，会依赖： 进程内组件Pinia Store，采用stub
        来替代，因为组件只依赖Store的数据

    -   

    -   #### 3.Vuex Store

        采用 组件测试，属于第一象限的测试 Vuex Store
        ：选择store独立测试的原因是，Store负责作为ViewModel操作的时候的存储数据，采用组件测试，是因为可以更快速的验证
        测试时，会依赖：
        进程内组件Service，采用stub来替代，因为组件只依赖Service发送数据请求

    -   #### 4.Service

        采用 组件测试，属于第一象限的测试，
        Service：选择Service独立测试的原因是，Service负责发送请求到BFF，采用组件测试，是因为可以更快速的验证
        测试时，会依赖：
        进程内组件Axios，采用stub来替代该组件，因为组件只依赖Axios发送网络请求

-   **我们可以按照以下步骤搭建一个基础的项目框架：**

-   {{embed (())}}

-   首先，你需要确保已经安装了Node.js和npm包管理器。如果没有安装，你需要先去安装。

-   创建一个新的空文件夹作为你的项目文件夹，并在该文件夹下打开终端。

-   运行以下命令初始化一个新的npm项目：

-     npm init -y

-   -   

-   安装vite和vue3 npm install -D vite vue@next

-   -   

-   创建一个vite配置文件（vite.config.js），并在其中添加以下内容：

-   import { defineConfig } from 'vite'
        import vue from '@vitejs/plugin-vue'
        - export default defineConfig({
        plugins: [vue()]
        })

-   在package.json文件中添加以下脚本：

-     {
          "scripts": {
            "dev": "vite",
            "build": "vite build"
          }
          }

-   安装ElementUI组件库和它的样式文件：

-     npm i element-plus -S

-   在main.ts文件中引入ElementUI组件库和样式文件：

-   import { createApp } from 'vue'
        import ElementPlus from 'element-plus'
        import 'element-plus/dist/index.css'
        import App from './App.vue'
        - createApp(App).use(ElementPlus).mount('#app')

-   创建一个App.vue文件，并添加以下内容：

-   <template>
        <div>
          <el-button>这是一个ElementUI按钮</el-button>
        </div>
        </template>
        - <script lang="ts">
        import { defineComponent } from 'vue'
        - export default defineComponent({
        name: 'App'
        })
        </script>

-   运行以下命令启动开发服务器：

-     npm run dev

-   至此，你已经搭建好了一个简单的Vue3 +
    ElementUI的前端项目。你可以在这个基础上继续添加你自己的代码和功能。

-   <data:image/svg+xml,%3csvg%20xmlns=%27http://www.w3.org/2000/svg%27%20version=%271.1%27%20width=%2738%27%20height=%2738%27/%3e>

-   如果你需要添加Vue3版本的vue-router路由，你可以按照以下步骤进行：

-   安装vue-router：

-     npm i vue-router@4  -S

-   创建一个router文件夹，并在其中创建一个index.ts文件，添加以下内容：

-   import { createRouter, createWebHistory } from 'vue-router'
        import Home from '../views/Home.vue'
        - const routes = [
        {
          path: '/',
          name: 'Home',
          component: Home
        },
        // 在这里添加其他路由配置
        ]
        - const router = createRouter({
        history: createWebHistory(),
        routes
        })
        - export default router

-   在main.ts文件中引入并使用router：

-   import { createApp } from 'vue'
        import ElementPlus from 'element-plus'
        import 'element-plus/dist/index.css'
        import App from './App.vue'
        import router from './router'
        - createApp(App).use(ElementPlus).use(router).mount('#app')

-   在App.vue文件中添加`<router-view>`{=html}组件：

-   <template>
        <div>
          <router-view />
        </div>
        </template>
        - <script lang="ts">
        import { defineComponent } from 'vue'
        - export default defineComponent({
        name: 'App'
        })
        </script>

-   至此，你已经成功添加了Vue3版本的vue-router路由支持。你可以在router/index.ts文件中添加其他路由配置，如需要。
